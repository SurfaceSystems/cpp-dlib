# dlib
Library and program downloader from terminal.
Works on Windows and Linux :)

## Installation
Read the guide [here](https://surfacesystems.github.io/cpp-dlib/get/).

## Some commands:
```
dlib script.dls
dlib install mank-git
dlib --repository add repository.com
dlib https://repository.com/sample/script.dls
dlib --version
```
The first command runs a script that is in the working folder.
The second command runs an indexed script from a remote repository.
The third command adds a repository.
The fourth command runs a script from the internet.
The last command shows dlib version.
