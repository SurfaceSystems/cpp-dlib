If you decided to install dlib, you maybe are a little lost, but don't worry. You'll learn here the basics of this program.

First, you'll need to add a repository for dlib to read scripts for the internet. I recommend you adding the official dlib repository using the dlib --repository add command like this: dlib --repository add elitees.github.io/dlib-index.

Then, you can install programs using the dlib install command. For example, if you want to install the latest version of mank, you can run dlib install mank-git.
