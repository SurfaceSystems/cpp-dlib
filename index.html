Welcome to the dlib website!

dlib is a lightweight, modern C++ library and program downloader. It includes its own programming language and other features like remote repositories that let the user download programs or libraries and install them with a simple command.

On this website, you'll find information about dlib's features, documentation, and how to download and install it.
