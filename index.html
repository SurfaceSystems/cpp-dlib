Purpose

dlib is a lightweight C++ programming language designed for library and program downloading.

Simple
Easy syntax to create scripts for programs and libraries.
Open-source
GPL v3.0 Licensed and free to use and modify.
Cross-platform
Native for Linux and Windows
Lightweight
Just downloading dlib executable you can use it for anything.

Get it

Clone the repo and build from source

git clone https://github.com/SurfaceSystems/cpp-dlib.git
cd cpp-dlib
# Linux:
make install
# Windows (PowerShell):
.\build.ps1 -Install

Install

You can install dlib by cloning the repository and building from source.

git clone https://github.com/SurfaceSystems/cpp-dlib.git
cd cpp-dlib
# Linux:
make install
# Windows (PowerShell):
.\build.ps1 -Install

Quick start

Add dlib official index and update scripts.

dlib --repository add elitees.github.io/dlib-index
dlib --repository update

Add another repository if you need it.
